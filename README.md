# Cockpit

Persönliche Web-App (GitHub Pages) fürs iPhone: Startseite mit Kacheln (Stunden, laufende Kosten, Arbeitsnachweis, Jahr, Urlaub, Notizen, Geburtstage, Depot) und Jarvis.

- `index.html` – die ganze App (Design, Fenster, Funktionen, Jarvis-Kugel)
- `rechnen.js` – Regeln zur Stundenberechnung
- `pdf.js` – Stundennachweis als PDF
- `sw.js` – Offline-Start und Updates (Cache-Name bei jeder Version hochzählen)
- `manifest.webmanifest`, `cockpit-*.png` – Name, Logo, Startbild

Die Daten liegen nicht hier, sondern in einem privaten Repo und als Kopie auf dem Gerät.
